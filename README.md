i can# RestaurantReservation-PythonHaskell
A Restaurant Reservation System implemented in two programming paradigms: Python (Object-Oriented Programming) and Haskell (Functional Programming).

## Structure
- [`python/`](python/) — OOP implementation. See [python/README.md](python/README.md) to set up and run.
- [`haskell/`](haskell/) — FP implementation. See [haskell/README.md](haskell/README.md) to set up and run.
- [`docs/design/`](docs/design/project-structure.md) — shared architecture and diagrams.
- [`docs/modules/`](docs/modules/) — per-member working files (design, implementation, test cases).
- [`Report.md`](Report.md) — the group report, assembled from the files above.
