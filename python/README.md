# Python Implementation (OOP)

Plain scripts, no packages or dependencies beyond the standard library.

## Run
```
cd python
python main.py
```

## Layout
- `main.py`: menu-driven entry point.
- `customer.py`: Customer model and CustomerManager (add, view, update, delete).
- `reservation.py`: Reservation model and ReservationManager (create, view, update, cancel).
- `table.py`: Table model and TableManager (availability, double-booking check).
- `search.py`: search, filter, and reporting over reservations.
- `validation.py`: shared input validation.

See [../docs/design/project-structure.md](../docs/design/project-structure.md) for the overall design.
